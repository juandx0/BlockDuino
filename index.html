📚 Guía para usuarios de micro:bit

¿Vienes de Microsoft MakeCode? Aquí tienes las equivalencias.

Conceptos básicos

Al iniciar Arduino

Equivale a los bloques de inicio. Se ejecuta una sola vez.

void setup() { }
Por siempre

Equivale al bloque para siempre de micro:bit. Se repite constantemente.

void loop() { }
Esperar milisegundos

En micro:bit puedes encontrar una pausa en milisegundos.

delay(1000);

Equivalencias de hardware

Leer un pin analógico

Lee valores de sensores analógicos. En Arduino UNO normalmente devuelve valores de 0 a 1023.

analogRead(A0)
Leer un pin digital

Lee si una entrada digital está HIGH o LOW.

digitalRead(2)
Escribir un pin digital

Enciende o apaga una salida.

digitalWrite(13, HIGH);
Salida analógica PWM

Controla una salida PWM. En Arduino UNO utiliza valores de 0 a 255.

analogWrite(9, 128);

Matemáticas y lógica

  • + Sumar.
  • - Restar.
  • × Multiplicar.
  • ÷ Dividir.
  • =, !=, <, > Comparar valores.
  • AND Ambas condiciones deben cumplirse.
  • OR Al menos una condición debe cumplirse.
  • NOT Invierte una condición.

Una diferencia importante

Arduino no tiene los mismos pines ni las mismas capacidades que micro:bit. Comprueba siempre qué placa estás usando en Tinkercad.
